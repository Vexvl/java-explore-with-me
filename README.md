# Explore-With-Me

**Explore-With-Me** - сервис афиши, в котором пользователи могут создавать события, искать интересные мероприятия и собирать компанию для участия.  
Проект выполнен в рамках курса Java-разработчик от Яндекс Практикума.

---

## Возможности

- Создание и редактирование событий.  
- Просмотр списка доступных мероприятий.  
- Подписка и участие в событиях других пользователей.  
- Статистика просмотров и активности.  

---

## Технологии

- Java 11+  
- Spring Boot  
- Spring Data JPA (Hibernate)  
- PostgreSQL  
- Lombok  
- Maven  
- Docker / Docker Compose (для запуска сервисов)
